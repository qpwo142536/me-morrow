# ME:MORROW — 웹 프로토타입

미모로우 UX/UI 기획을 바탕으로 만든 반응형 웹 프로토타입입니다.

## 실행 방법
- `index.html` 파일을 브라우저에서 열면 기본 화면을 확인할 수 있습니다.
- 인터넷 연결이 있으면 Google Fonts가 적용됩니다. 오프라인에서는 기본 글꼴로 표시됩니다.

## GitHub에 올리기
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 저장소 안에서 **Add file → Upload files**를 선택합니다.
3. 압축을 푼 폴더 안의 `index.html`, `css` 폴더, `js` 폴더, `README.md`를 업로드합니다.
4. **Commit changes**를 누릅니다.
5. 저장소의 **Settings → Pages**로 이동합니다.
6. **Deploy from a branch**를 선택하고 Branch는 `main`, Folder는 `/(root)`로 설정한 뒤 Save를 누릅니다.
7. 잠시 후 표시되는 Pages 주소로 접속합니다.

## 현재 구현된 기능
- 오늘의 접수창구 대시보드와 의뢰 통계
- 빠른 의뢰 입력 및 접수증 생성
- 의뢰 등록 폼 (날짜, 시간, 예상 소요, 보상, 응원 메모)
- 접수 대기 → 수락 → 완료 상태 변경
- 미완료 의뢰 재계획 및 주 3회 재협상 가드레일(프로토타입 카운터)
- 20분 Micro-Quest 분할 시뮬레이션
- 완료 스탬프 기록
- 성취 리포트 지표
- 알림/보증인/데이터 설정 화면
- 모바일/PC 반응형 레이아웃

## 구현 범위와 한계
이 버전은 **프론트엔드 프로토타입**입니다. 의뢰 데이터는 현재 브라우저의 `localStorage`에 저장되므로 다른 기기와 자동 동기화되지 않습니다. 빠른 입력 파싱과 20분 과업 분할은 규칙 기반 데모이며 실제 생성형 AI API를 호출하지 않습니다. 푸시 알림, 친구에게 보내는 알림, Google/Apple 캘린더 동기화, 로그인/계정 간 데이터 공유에는 별도 백엔드와 인증·API 연동이 필요합니다. 공개 저장소에 비밀 키를 올리지 마세요.
